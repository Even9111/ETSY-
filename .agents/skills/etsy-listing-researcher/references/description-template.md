# Etsy long-form description template

Use this as a structure, not as boilerplate to copy verbatim. Replace every bracketed field with verified product facts. Adapt section count to the item: a small keychain may need fewer sections; a multi-use strap may use all of them.

## Style rules

- Start with one emoji-led, benefit-focused headline. Choose symbols that fit the product's colors and motif: bows/pearls for coquette, flowers for floral, stars/moons for celestial, leaves for botanical, hearts for romantic, waves/shells for coastal, etc.
- Use Markdown-style bold headings and short paragraphs. Keep the English natural and buyer-facing.
- Use emojis as visual anchors, not keyword substitutes. Usually one or two per section is enough.
- Put the primary product phrase and its main benefit in the first paragraph, but do not keyword-stuff.
- Use exact, verified claims for materials, measurements, hardware, variants, included pieces, adjustability, and compatibility.
- Add an IMPORTANT NOTE section only for a real product-specific variation, care issue, color difference, or construction detail that a buyer should know before ordering.
- Add gift language only when the item genuinely fits the recipient or occasion.
- Do not copy a competitor's wording, distinctive claims, or unsupported “heavy-duty,” “anti-drop,” “fits all,” or “won't break” promises. Use cautious wording when the product evidence does not support a guarantee.

## Recommended structure

```text
**[emoji] [Primary aesthetic or product benefit] [emoji]**

[Keep the opening paragraph natural and search-aware. Name the product, its strongest visual feature, its main use, and its buyer benefit.]

**✨ [X]-in-1 Versatile Design:**

**For [use case 1]:** [Concrete, verified benefit and how the buyer uses it.]

**For [use case 2]:** [Concrete, verified benefit and compatible component, if any.]

**For [use case 3]:** [Concrete, verified benefit.]

**🧵 [Craftsmanship / Materials / Construction]:**

Crafted with [verified construction].

**Top Layer / Main Feature:** [Verified material, motif, texture, or embellishment.]

**Base / Hardware / Support:** [Verified base, clasp, ring, connector, or lining.]

**⚠️ IMPORTANT NOTE:**

[Only include a verified product-specific note. Otherwise omit this section.]

**📏 Dimensions:**

**Length:** [verified measurement]

**Width / Size:** [verified measurement]

**🎨 Colors & Options:**

[List verified colors, patterns, finishes, personalization, or hardware choices.]

**📦 What's Included:**

1 x [verified item]

1 x [verified item]

**💌 Customer Service:**

If there is anything you're not satisfied with, please contact me before leaving a review, and I'll do my best to help.
```

## Emoji selection guide

Choose from the product evidence rather than applying a fixed template:

| Product cue | Possible visual language |
|---|---|
| Lace, bows, pearls, pink/black romantic styling | 🎀 ✨ 🖤 💗 |
| Flowers, embroidery, botanical motifs | 🌸 🌼 🌿 🪻 |
| Cottagecore, natural fabric, earthy colors | 🍃 🤎 🧺 🌾 |
| Phone/camera utility and hands-free use | 📱 📷 🙌 |
| Jewelry, charms, sparkle, metallic hardware | 💎 ✨ 🪞 |
| Travel, outdoor, coastal, summer motifs | 🧳 🌊 🐚 ☀️ |

Use only the symbols that match the actual item and keep the final description readable for search and accessibility.
